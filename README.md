# Con Recuerdos

Página web estática de presentación para una asociación que acompaña a personas con Alzheimer y a sus familias.

## Abrir la web

Abre `index.html` en un navegador. No requiere instalar dependencias ni ejecutar un servidor.

## Antes de publicarla

- En `script.js`, configura `CONTACT_EMAIL` con una dirección real de la asociación. El formulario prepara un correo en la aplicación de correo de la persona visitante; no envía datos a un servidor.
- En `index.html`, sustituye la dirección y el horario de ejemplo por los datos reales.
- Revisa las imágenes y reemplázalas por fotografías autorizadas de la asociación si lo prefieres.
- Añade los datos de contacto, redes sociales y cualquier información práctica que quieras compartir.

Las imágenes de ejemplo y las fuentes tipográficas se cargan desde servicios externos, por lo que necesitan conexión a Internet.
